## Adding a talk

Speakers use the **iTabs This Talk skill** (`skill/SKILL.md`, live at talk.itabs.co/skill/SKILL.md, and the "Make your own" button on every page). They add it to Claude and say "make my talk page". Claude writes the talk MD, makes a `<slug>/` folder like `aidan/`, and makes a QR code for their last slide. They send the folder to Jon, who adds it at the repo root, lists it here and in `index.html`, and pushes.
